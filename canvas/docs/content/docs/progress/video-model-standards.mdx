本页描述已实现、尚待真实渠道验收的适配，不代表全部厂家账号、代理渠道或版本均已可用。

## 节点选择

- 「接口标准」按模型名称识别具体系列；渠道别名或未知模型可手动选择，也可使用「通用 / 自定义」。不替换用户选择的实际模型 ID。
- 「请求格式」与型号能力分开：「自动」根据实际地址和渠道格式选择；「兼容网关」沿用现有网关合同；「厂家原生」选择相应序列化、创建和查询接口。手动选择原生不会更换渠道地址、凭据或账号分组。
- 时长、比例、分辨率、首尾帧 / 全能参考 / 编辑 / 延长及声音开关按系列显示，部分规则在取得实际参考素材后联动。Seedance 2.5 编辑随源时长、首尾帧 / 编辑 / 延长使用 adaptive；Veo 延长使用 720p，高分辨率及参考图任务采用 8 秒；Hailuo 1080p 采用 6 秒；O1 纯首尾帧采用 5 / 10 秒。
- 参考上限、已知总时长及部分文件条件默认只提示，开启「严格校验」才由这些条件阻止提交。原生接口无法表达的组合仍明确报错，不静默删除、截断或只转发第一份素材。严格校验不是完整的媒体探测，不保证编码、尺寸、大小及所有条件均满足上游要求。
- 节点保存标准、格式、校验方式、模式、负面提示词、种子和档位；结果重试与刷新续查保留任务类型及查询路径。自定义模型脚本优先于内置直连协议，收到新增标准参数，具体上传与字段仍由脚本负责。

## 原生请求与托管边界

| 标准 | 创建 / 查询 |
| --- | --- |
| Ark / Seedance | `/api/v3/contents/generations/tasks`；同路径加任务 ID |
| MiniMax H3 | `/v2/video_generation`；`/v2/query/video_generation/{id}` |
| Hailuo | `/v1/video_generation`；`/v1/query/video_generation?task_id=`；完成后通过 `/v1/files/retrieve` 获取文件 |
| Veo | `models/{model}:predictLongRunning`；operation 查询与鉴权下载 |
| Gemini Omni | `/v1beta/interactions`；读取 model_output 视频，Files ACTIVE 后鉴权下载 |
| 可灵新版 | `/text-to-video/kling-3.0[-turbo]`、`/image-to-video/kling-3.0[-turbo]`、`/omni-video/kling-3.0-omni` 或 `/omni-video/kling-o1`；统一 `/tasks?task_ids=` |
| 可灵旧版 | `/v1/videos/text2video` 或 `/v1/videos/image2video`；按原类型查询 |

托管请求继续走 Sub2API 的用户鉴权、原账号调度、任务归属、预扣结算及对象存储转存。OpenAI API Key 分组可对上述 MiniMax / 可灵 / Ark / Omni 原生进行转换，账号需配置真实厂家地址及可用凭据。Veo 原生需要 Gemini 分组；该分组目前不提供 Omni Interactions，Omni 可通过配置 Google 地址的 OpenAI API Key 分组并手动选「Gemini Omni / 厂家原生」，或使用已支持该型号的兼容网关。节点不会自动迁移分组。

兼容网关不等于厂家原生，第三方私有字段需要该渠道的模型脚本。配置 `/api/v3` 原生账号却强制兼容格式会明确报错；修改地址后新建任务。后台 R2 仍仅覆盖托管参考输入，第三方浏览器直连不自动借用服务器桶。Seedance 官方视频参考为 MP4 / MOV，深度 WebM 不会自动转码。可灵新版图片接受 URL 或 Base64，视频必须是 HTTP(S)。

Omni 原生请求选择 URI 交付；若上游忽略交付设置并返回超大 inline 响应，仍受网关响应大小保护限制。无直接时长参数的型号按现有托管预估规则预扣，输出未返回实际时长时不能视为已按实长验收。
