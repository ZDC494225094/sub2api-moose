# 计费与调度增强模块 (billing-scheduling)

## 功能范围

计费与调度的增强功能，包括：

- **分组倍率同步**：用户分组的计费倍率自动同步
- **渠道分时定价**：支持不同时段的差异化定价
- **自定义分组用量**：自定义用量统计和计算规则
- **组合调度**：复杂的资源调度策略

## 架构约束

### 历史数据不可变性

**已发生的用量和账单记录必须保持不变**，无论扩展开关状态如何：

1. **用量记录 (usage)** - 已记录的用量不能重算或修改
2. **账单记录 (billing)** - 已生成的账单不能随开关重新计算
3. **计费缓存 (billing_cache)** - 历史缓存数据保持原值

### 扩展控制行为

**扩展开启时：**
- 允许使用自定义倍率
- 启用分时定价规则
- 应用自定义用量计算
- 使用组合调度策略

**扩展关闭时：**
- 回退到基础计费模式（无倍率增强）
- 使用标准定价（无分时差异）
- 使用标准用量计算
- 使用简单调度策略
- **历史数据不受影响** - 已产生的用量和账单保持不变

## 集成策略

由于计费调度功能高度耦合，采用**渐进式解耦**策略：

1. **Stage 1 (当前)**: 定义准入接口，标记功能边界
2. **Stage 2**: 按端口拆分（RateMultiplier、TimePricing、CustomUsage、CompositeScheduling）
3. **Stage 3**: 集成准入检查到各服务
4. **Stage 4**: 验证开关不影响历史数据
